# Mariano Portfolio

React + Vite + Tailwind CSS portfolio for Mariano, an AI Automation Specialist, GoHighLevel CRM Builder, and Web Developer.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/components` — reusable portfolio sections
- `src/App.jsx` — page composition
- `src/main.jsx` — React entry point
- `src/index.css` — Tailwind and global styles
- `public/profile.jpg` — add Mariano's profile photo here
